PORTEFEUILLE CARTE - Version 2.0

Nouvelle organisation :
1. Écran d'accueil PORTEFEUILLE
2. Bouton MES CARTES
3. Scanner une carte
4. Ajouter une carte manuellement
5. Afficher le code-barres d'une carte enregistrée

Fonctions :
- Scan code-barres et QR code
- Nom du magasin
- Enregistrement local sur le téléphone
- Affichage du code-barres en grand
- Suppression par appui long
- Compteur de cartes

Compilation :
1. Ouvrir le dossier dans Android Studio.
2. Laisser Gradle synchroniser.
3. Brancher un téléphone Android et lancer.
4. Pour générer un APK : Build > Build APK(s).
