# Portefeuille Carte Design V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Moderniser toutes les pages de PORTEFEUILLE CARTE, améliorer le scan d’une carte complète avec photo/logo et détection du commerce, rendre le retour visible, ajouter Quitter, et un petit admin local pour des publicités d’affiliation légères.

**Architecture:** Conserver l’application Android Kotlin actuelle et son stockage sécurisé local. Ajouter une couche de logique testable pour la détection du commerce et les publicités, puis refaire l’interface dans MainActivity avec un thème bleu nuit/or, capture photo de carte via caméra système, OCR ML Kit, et écrans Offres/Admin.

**Tech Stack:** Kotlin, AndroidX AppCompat/Biometric, ML Kit Text Recognition, Google Code Scanner, ZXing, Android Keystore.

**Spec:** aperçu visuel validé dans la conversation du 31 août 2026.

## Global Constraints
- Android minSdk 26, targetSdk 35.
- Conserver mot de passe + biométrie et stockage local chiffré.
- Publicités discrètes, administrables localement, sans collecte de données.
- Le scan complet doit conserver la photo de la carte et proposer automatiquement un nom de commerce détecté par OCR.
